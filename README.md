# Water_level_detector
#Overview

This project implements a Water Level Detector System using Finite State Machine (FSM) in Verilog HDL. The design monitors different water levels using sensor inputs and indicates the tank condition through Green, Blue, and Red LEDs.

The project was designed and simulated in Xilinx Vivado using RTL design methodology and waveform verification.

#Features
FSM-based water level monitoring
Verilog HDL implementation
LED indication for different water levels
RTL schematic generation
Behavioral simulation and waveform analysis
Synchronous state transition design


#Tools Used
Verilog HDL
Xilinx Vivado
RTL Simulation
Behavioral Simulation
